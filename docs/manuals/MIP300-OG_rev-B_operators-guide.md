# Meridian IP-300 — Operator's Guide

| Field | Value |
|---|---|
| Document ID | MIP300-OG |

## 1. Overview
The IP-300 delivers fluids at a programmed rate through an approved tubing set. Operators are responsible for following facility protocols and clinical orders.

## 2. Setup

### 2.1 Power
Connect to mains or run on battery. The battery icon shows remaining runtime.

### 2.2 Selecting a tubing set
Use only MIP-SET-100 or MIP-SET-200.

### 2.3 Loading the tubing set
1. Open the door.
2. Insert the pump segment into the channel with the arrow pointing down.
3. Close the door until it latches.
4. Prime the set before connecting to the patient.

## 3. Alarms

### 3.1 Alarm overview
When an alarm occurs the pump stops delivery, sounds a tone and shows a code. See the Alarm & Error Reference (MIP300-AER) for the meaning of each code.

### 3.2 Clearing an alarm
Remove the cause, then press **Clear**. If the alarm returns, do not continue use; contact your biomedical department.

### 3.3 Operator limits
Operators must not open the housing, change service settings or adjust calibration.
